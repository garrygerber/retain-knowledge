# Contributing

Please open an issue to discuss substantial changes. Keep the skill portable across agents, distinguish verified outcomes from hypotheses, and avoid adding secrets or user-specific information.

Before proposing a change, check the skill metadata and test the installer in an isolated temporary directory for both supported agents. Verify that a second install refuses to overwrite an existing skill, and inspect `npm pack --dry-run` before releasing.

The repository currently has no open-source license. The owner must choose a license before reuse or distribution terms can be granted.
